1. Konsep Dasar Pemrograman Web
Pemrograman web merupakan bagian dari pengembangan perangkat lunak yang digunakan untuk membangun layanan atau aplikasi yang dapat diakses melalui teknologi web.
2. Arsitektur Klien-Peladen
Arsitektur klien-peladen merupakan model komunikasi yang membagi peran antara klien (client) sebagai pihak yang meminta layanan dan peladen (server) sebagai pihak yang menyediakan atau memproses layanan. Dalam konteks aplikasi web, peramban yang digunakan pengguna berperan sebagai klien. Klien mengirimkan permintaan ketika pengguna membuka suatu alamat web atau melakukan aktivitas tertentu pada aplikasi. Peladen merupakan sistem yang menerima permintaan dari klien dan memberikan respons yang sesuai. Respons tersebut kemudian diterima oleh klien dan dapat ditampilkan kepada pengguna melalui peramban. 
3. HTTP Request dan Response
 1 HTTP Request, yaitu permintaan yang dikirimkan oleh klien kepada peladen; 
 2. HTTP Response, yaitu respons yang dikirimkan oleh peladen kepada klien setelah permintaan diterima dan diproses.
4. HTML, CSS, JavaScript, PHP, MySQL
HTML HTML (HyperText Markup Language) digunakan untuk menyusun struktur dan konten halaman web. HTML menentukan elemen-elemen yang terdapat pada halaman, misalnya: judul; paragraf; tautan; gambar; daftar; tabel; dan formulir. Secara konseptual, HTML dapat dipahami sebagai teknologi yang membentuk struktur dasar halaman web.
CSS CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan dan penyajian halaman web. CSS dapat digunakan untuk mengatur antara lain: jenis dan ukuran teks; jarak antarelemen; tata letak; ukuran elemen; warna; tampilan berbagai komponen halaman; dan penyesuaian tampilan pada ukuran layar yang berbeda. 
JavaScript JavaScript digunakan untuk menambahkan perilaku dan interaksi pada sisi klien. JavaScript memungkinkan halaman web merespons aktivitas pengguna atau melakukan perubahan tertentu tanpa hanya mengandalkan struktur HTML dan tampilan CSS. 
PHP PHP digunakan untuk melakukan pemrosesan pada sisi peladen. Ketika aplikasi web membutuhkan proses yang tidak cukup dilakukan pada sisi klien, peladen dapat menjalankan program PHP untuk mengolah permintaan yang diterima. 
MySQL MySQL merupakan sistem manajemen basis data yang digunakan untuk menyimpan dan mengelola data aplikasi. Dalam aplikasi web, data sering kali perlu disimpan agar dapat digunakan kembali. Contohnya adalah data mahasiswa, data pengguna, data produk, atau data lain yang diperlukan oleh aplikasi. 
5. Hubungan Antarteknologi
Hubungan HTML, CSS, JavaScript, PHP, dan MySQL dalam membuat website bisa dibayangkan seperti sebuah restoran:
HTML → struktur/tampilan dasar halaman
CSS → mengatur desain dan tampilan
JavaScript → membuat halaman interaktif
PHP → mengolah data dan menjalankan logika di server
MySQL → menyimpan data
